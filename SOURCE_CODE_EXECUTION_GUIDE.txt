NEUROLEARN AI: SOURCE CODE EXECUTION GUIDE
================================================================================
An Intelligent Learning Operating System Using Machine Learning and Knowledge Graphs
Target Platforms: Windows (PowerShell / Command Prompt) / Linux / macOS
Stack: PostgreSQL 16 + FastAPI (Python ML) + Express 5 (Node.js) + React 18 (Vite)
================================================================================

1. SYSTEM TOPOLOGY & PORTS
--------------------------------------------------------------------------------
- Database:         PostgreSQL 16 Alpine      Port: 5432
  Stores: Users, Cohorts, Graph Schema, Quiz Attempts, and Student Digital Twins.

- ML Microservice:  FastAPI + XGBoost + SHAP  Port: 8000
  Stateless engine: Risk prediction, SHAP attribution, and Prerequisite Root Gaps.

- Backend Gateway:  Node.js (LTS), Express 5  Port: 3001
  API orchestration, JWT authentication, rate limiting, and ML cache resilience.

- Frontend Client:  React 18 + Vite           Port: 5173
  Interactive Cytoscape.js DAG, Chart.js analytics, Student and Faculty Dashboards.

3. STEP-BY-STEP SERVICE STARTUP SEQUENCE
--------------------------------------------------------------------------------
Open 4 dedicated terminal sessions and launch the services in order:

[TERMINAL 1] PostgreSQL Database Startup, Migration & Seeding
-------------------------------------------------------------
1. Start PostgreSQL container:
   docker compose up -d db

2. Verify connection:
   docker compose exec db psql -U neurolearn -c "SELECT version();"

3. Apply database migrations:
   PowerShell: .\scripts\reset.ps1
   Linux/Mac:  ./scripts/reset.sh

4. Generate synthetic datasets and seed database:
   PowerShell: .\scripts\seed.ps1
   Linux/Mac:  ./scripts/seed.sh


[TERMINAL 2] ML Microservice (FastAPI + XGBoost + SHAP)
-------------------------------------------------------
1. Navigate to ML directory:
   cd ml-service

2. Install dependencies (if not already done):
   pip install -r requirements.txt

3. Start server with live reload:
   python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload

4. Health Check:
   Open browser: http://127.0.0.1:8000/ml/health
   Expected: {"status": "ok", "modelVersion": "1.0.0", "graphNodes": 38}


[TERMINAL 3] Backend Gateway (Node.js + Express 5)
--------------------------------------------------
1. Navigate to backend directory:
   cd backend

2. Install dependencies:
   npm install

3. Start development server:
   npm run dev

4. Health Check:
   Open browser: http://127.0.0.1:3001/health
   Expected: {"status": "ok", "database": "connected", "ml": "healthy"}


[TERMINAL 4] Frontend Client (React 18 + Vite)
----------------------------------------------
1. Navigate to frontend directory:
   cd frontend

2. Install dependencies:
   npm install

3. Launch dev client:
   npm run dev

4. Access Web Application:
   Open browser: http://localhost:5173

7. TROUBLESHOOTING MATRIX
--------------------------------------------------------------------------------
Symptom:    ECONNREFUSED 127.0.0.1:5432
Cause:      PostgreSQL container is stopped or local service is inactive.
Resolution: Run 'docker compose up -d db' and verify with 'docker ps'.

Symptom:    401 Unauthorized on ML endpoints
Cause:      Mismatch between ML_API_KEY in backend and ML service.
Resolution: Ensure ML_API_KEY is identical across root .env and ml-service environment.

Symptom:    CORS error in browser console
Cause:      CORS_ORIGIN configuration mismatch.
Resolution: Ensure CORS_ORIGIN=http://localhost:5173 with no trailing slash in .env.

Symptom:    Playwright E2E browser launch error
Cause:      Browser binaries not installed.
Resolution: Run 'npx playwright install --with-deps' inside frontend directory.
